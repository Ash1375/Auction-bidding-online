# Auction & Bidding System with Real-Time Update

## Modules
1. User Authentication & Profile Management
2. Auction Item Management
3. Real-Time Bidding Engine
4. Live Notifications & Dashboard
5. Payment Gateway Integration (Teammate)
6. Analytics & Reporting Dashboard (Teammate)
7. Admin Panel (Teammate)

## Run Instructions
```
cd backend && npm install && npm run dev
cd frontend && npm install && npm run dev
```
